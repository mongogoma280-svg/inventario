
## Registrar nuevos productos especificando su nombre y cantidad disponible.  

## Consultar un listado general de los productos almacenados con su respectivo ID, fecha de registro y estado de disponibilidad (Disponible o Sin existencia). 

## Validar campos vacíos o cantidades numéricas incorrectas de manera automática

----------------------------------------------------------------

## Backend: PHP 8.2.12 
## Base de datos: MariaDB / MySQL.  
## Gestor de BD / Entorno: XAMPP y HeidiSQL.  
## Frontend: HTML5 y CSS3S

--------------------------------------------------------------

## Un entorno de servidor local que soporte PHP y bases de datos, como XAMPP.  

## Base de datos:Crear una base de datos en blanco llamada inventario.  Importar el archivo proporcionado base_datos.sql para generar la estructura de la tabla y los registros iniciales.  

## Importar el archivo de la base de datos (inventario.sql) en el gestor de bases de datos para crear la estructura de la tabla productos y cargar la información inicial.  

## XAMPP: Tener instalado y activo el servidor local con soporte para Apache y MySQL/MariaDB. 

## Despliegue local: Colocar los archivos del proyecto dentro de la carpeta htdocs de XAMPP y acceder a través del navegador mediante http://localhost/inventario.
